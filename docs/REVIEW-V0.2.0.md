# v0.2.0 专家协作记录

同一项目 Grok Bot 完成方案审查、一次行为批次、实现审查与针对性复核。专家自己读了公开 v0.1 基线，实现差异由 Codex 从工作树提供，未声称专家直接访问 Mac。

重要意见及处理：

- MCP 不经过 CLI 本地登记：文档明确未提供本地去重，要求未知结果只读回。
- 方法偏离原因必须独立成行：协议及测试固定合法枚举行。
- 同 Bot 不是盲测：NEXT、BASELINE 与 evals 记录限制。
- 多行材料可读性：采用动态长度围栏，新增围栏边界测试；它不是安全沙箱。
- 未指定方法不能冒充协调者建议：默认显示未指定。
- 用户角色回显过滤需真实兼容性验证：部署后 CLI 读取旧真实任务，protocol_valid=true，专家本轮完成声明=true，quality_verified=false。
- 反馈模板和示例需复核：专家实际读取提供原文，确认没有新增权限或自动写入。

最终针对性复核：没有阻塞问题。其指出行为批次早于围栏改动，已在 RESULTS 如实标注，不另行扩大测试。评审不替代 Codex 验证；同一 Bot 多轮不等于多位独立专家。

根目录 README 按用户规则未修改，当前版本使用说明见 V0.2.0.md，变更见 ../CHANGELOG.md。

# Baseline — 2026-11-10

当前已部署能力的可移植源码基线：一项目一 Bot、账户隔离、四种工作模式、单次派单、主动读回、任务状态及回复完整性检查。技能、专家协议和桥接代码一起保存。

公开整理仅移除个人路径、账户状态、迁移绑定和特定设备诊断记录；启动器使用显式环境配置。本机运行副本未被替换。

已做的运行验证：Mac Node 24 / grok-bot-cli 0.12.5 的 MCP 初始化及工具发现；真实项目 Bot 的两轮方案讨论。它们不代表其他机器或 Windows/Linux 的运行保证。仓库测试验证回复协议边界，不联系任何 Bot。

下一阶段尚未实施：专家可对调用方建议的方法提出调整、信息依赖披露、建议结果追踪与立场变化记录、基于真实案例的质量评估。默认项目读取权和 Bot 持久记忆权限均未扩大。

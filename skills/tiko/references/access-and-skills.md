# 访问与技能加载

本机 CLI、Bot 默认执行环境和注册设备是不同层。需要本机文件时先发现正确设备，再通过支持 machineId 的工具读取授权范围；目录可见不等于技能或规则已加载。

宿主用户技能、Grok 共享技能库、项目规则分别发现和加载，不自动互相继承。任务包明确所需路径、材料来源及权限。工具与设备能力以当前返回为准，不硬编码设备 ID。

`node bridge/launch.mjs cli doctor --json` 检查本机状态，`node bridge/launch.mjs cli skills list --gateway --json` 查询共享技能元数据。不要输出凭据、批量导出状态或无关历史。

`gbot skills add` 影响共享技能库，不是项目专属挂载；不得默认上传用户全部技能、私有规则或凭据。默认通过本轮明确材料交接；只有用户指定同步范围时才另行同步。原始本机诊断记录不随公开基线发布。

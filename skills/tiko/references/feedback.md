# 建议与结果反馈

优先使用项目已有决策/验证记录，仅对重要建议记录，不为每轮强制建文档。本模板不授予写入项目或 Bot 记忆的权限，实际写入由 Codex 在用户授权范围内完成。

```text
建议 ID / 原任务 ID：
原建议与依据：
处理：采纳 | 不采纳 | 待验证 | 保留分歧
处理理由 / 用户决定来源：
后续证据：<来源、版本、验证结果；未验证则明确>
当前判断及与原建议的差异：
改变判断的条件 / 下一步验证：
```

不把采纳等同于正确、不把否决等同于错误。仅当相关任务发生时回传记录。专家核对原建议后说明是否改变立场；不能仅凭“上次你说过”就杜撰历史，不可访问时报告依赖调用方转述。
